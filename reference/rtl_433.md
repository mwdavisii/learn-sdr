

## What It Is

rtl_433 decodes OOK/FSK transmissions from consumer ISM-band devices — weather stations, tire pressure sensors, doorbells, remote thermometers, pool sensors, and more. Ships with 200+ device decoders and outputs decoded data as JSON, CSV, MQTT, or plain text.

## Key Flags

| Flag | Purpose | Example |
|------|---------|---------|
| `-f` | Frequency (default 433.92 MHz) | `-f 433.92M` |
| `-f 315M` | Scan 315 MHz ISM band | `-f 315M` |
| `-F json` | JSON output to stdout | `-F json` |
| `-F mqtt://host` | Push to MQTT broker | `-F mqtt://192.168.1.x:1883` |
| `-M homeassistant` | Add HA auto-discovery prefix | `-M homeassistant` |
| `-R 0` | Auto-detect decoder | `-R 0` (default) |
| `-A` | Analyze unknown signals | `-A` |
| `-G` | Enable all decoders | `-G` (slow, for discovery) |
| `-v` | Verbose output | `-v` |

## Common Invocations

```bash
# Basic scan — see what's nearby
rtl_433

# JSON output
rtl_433 -F json

# Push to Home Assistant MQTT (auto-discovery)
rtl_433 -F mqtt://192.168.1.x:1883 -M homeassistant

# With MQTT auth
rtl_433 -F mqtt://user:pass@192.168.1.x:1883 -M homeassistant

# Also print to terminal while pushing to MQTT
rtl_433 -F mqtt://192.168.1.x:1883 -M homeassistant -F json

# Scan 315 MHz band
rtl_433 -f 315M

# Analyze an unknown signal
rtl_433 -A -f 433.92M
```

## HA Auto-Discovery

With `-M homeassistant`, rtl_433 publishes MQTT discovery payloads to `homeassistant/sensor/rtl_433_<device>/config`. Home Assistant picks these up automatically if the MQTT integration is configured. New sensors appear in Settings → Devices & Services → MQTT.

## Gotchas

- rtl_433 holds the RTL-SDR device exclusively. Close SDR++Brown or GQRX before running.
- Default frequency is 433.92 MHz; always specify `-f` explicitly when scanning other bands.
- The `-M homeassistant` flag requires the Mosquitto MQTT integration in HA to be active.
